# Setup BantuPelajar

## Groq
1. Buka `lib/config.ts`.
2. Cari `GROQ_API_KEY`.
3. Ganti `PASTE_GROQ_API_KEY_DI_SINI` dengan API key Groq kamu.
4. Deploy ulang ke Vercel.

Tidak perlu membuat Environment Variable untuk Groq.

## Supabase
Konfigurasi Supabase sudah berada di `lib/config.ts`.

## Build lokal
```bash
npm install
npm run build
```
